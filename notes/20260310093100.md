# Improve setup

- Add a shell script in `docker/setup/` that check the following conditions:
  - The user (expected to be `filestash`) has ownership of `/app/data` folder.
  - The following envvars are set: FILESTASH_S3_ENDPOINT, FILESTASH_S3_ACCESS_KEY, and FILESTASH_S3_SECRET_ACCESS_KEY.
  - Check that the following structure exists inside the container `/app/data/state/config/config.json`, if it doesn't exist copy `docker/setup/config.json` to `data/state/config/`.
  - Be sure `ca-certificates` is installed.
  - Log a friendly warning if any of these fails.
- Since the shell script needs the volume to be mounted it cannot be run at build time in the Containerfile.
- In `docker/Containerfile.filestash-prod`:
  - Add `filestash` to path.
  - Make sure to copy the setup dir to the container, so the config file and script are available.
- Make sure the script is run before filestash. (I think the cmd could be the script but I am sure there are more efficient ways).
